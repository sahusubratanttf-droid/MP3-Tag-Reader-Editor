📌 MP3 Tag Reader & Editor (C Project)

A command-line based MP3 metadata reader and editor built using C programming language.

🚀 Features

Detect ID3 version (ID3v1 / ID3v2.3)

Display all metadata information

Edit tags using command line options

Show help menu (-h)

Display embedded image details

Error handling if tag not found

🛠 Technologies Used

C Programming

File Handling

Structures

Modular Programming

ID3v2.3 Specification

⚙️ Usage

Compile:

gcc main.c tag_reader.c tag_editor.c -o mp3tag

Run:

Read tag:

./mp3tag -r song.mp3

Edit tag:

./mp3tag -e -t "New Title" song.mp3

Help:

./mp3tag -h
